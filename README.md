# ETL and Data Pipelines with Shell Airflow and Kafka + Project

This repository contains all the work I completed during the “ETL and Data Pipelines with Shell, Airflow and Kafka” specialization. It includes hands-on exercises, course practice files, Kafka topics work, Airflow DAGs, shell scripts and the final end-to-end ETL pipeline project.

The repository is organized into three main folders.

---

# Folder Details

## 1. Apache-Airflow-Course

This folder contains all practice work from the Airflow module, including:
Sample DAGs written with Python
Exercises on scheduling, operators and dependencies
Notes and practice scripts from SN Labs
This helped me understand how Airflow manages and orchestrates workflows.

---

## 2. Kafka-Course

This section includes all Kafka-related coursework:
Topic creation and management
Producer and consumer scripts
CLI commands and practical lab files
Message streaming practice
These exercises built a strong foundation in event streaming and message handling.

---

## 3. Project: Build ETL Data Pipelines with BashOperator (Apache Airflow)

This is the main project of the course. It includes a working ETL pipeline that:
Extracts raw data using a shell script
Transforms the data using Python
Loads the final dataset into an output directory
Runs the entire pipeline through an Airflow DAG using BashOperator.
